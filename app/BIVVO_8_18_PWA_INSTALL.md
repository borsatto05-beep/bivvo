# Bivvo 8.18 — Convite Inteligente de Instalação PWA

- Novo usuário: após Home/onboarding, convite aparece com atraso curto.
- Android/desktop compatível: um clique em **Instalar Bivvo** chama o prompt nativo diretamente; resta somente a confirmação obrigatória do navegador/SO.
- iPhone/iPad: mostra apenas os 3 passos exigidos pelo iOS quando não há API direta.
- Recusa automática: cooldown de 7 dias; instalação manual em **Você** continua disponível.
- PWA já instalado: convite automático não aparece.
- Analytics: oferta, clique, recusa, aceite do prompt, instalação confirmada e instruções iOS.
- Growth Center > Retenção: métricas e taxas do funil de instalação.
- Nenhum dado financeiro é usado para decidir ou medir o convite.
