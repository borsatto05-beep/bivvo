# Fase 11.75 — WhatsApp na Administração

- A aba **Usuários online** agora exibe o telefone/WhatsApp informado no cadastro.
- Quando o número é válido, aparece o botão **💬 WhatsApp**.
- O clique abre uma nova conversa no WhatsApp usando `wa.me`, com uma saudação inicial simples e editável antes do envio.
- Números brasileiros com 10 ou 11 dígitos recebem o DDI `55` apenas para montar o link.
- Se não houver telefone cadastrado ou o número for inválido, nenhum link é criado.
- O botão não envia mensagem automaticamente; o administrador confirma o envio dentro do WhatsApp.
- Nenhum dado financeiro do usuário é exposto nesta tela.
