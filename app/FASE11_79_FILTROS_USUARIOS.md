# Bivvo 11.79 — Filtros na aba Usuários

## Implementado
- Botão **Filtros** recolhível para manter a tela limpa.
- Filtro de status: Todos, Online agora e Offline.
- Filtro por origem de aquisição (Google, Facebook, TikTok, YouTube etc., conforme dados reais).
- Filtro por aba mais usada.
- Filtro por dispositivo.
- Filtro por sistema operacional.
- Busca ampliada para nome, e-mail, telefone, origem, aba, dispositivo e sistema.
- Contador “Mostrando X de Y usuários”.
- Botão “Limpar filtros”.
- Layout responsivo no celular.

Os filtros são aplicados apenas aos metadados administrativos já retornados pela API; não consultam valores financeiros pessoais.
